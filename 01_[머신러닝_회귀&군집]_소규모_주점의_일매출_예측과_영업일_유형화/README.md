# 소규모 주점의 일매출, 요일 말고 무엇이 움직이는가

## 요약 (Executive Summary)

- **데이터:** 신대방역 인근 소규모 주점 한 곳의 POS 일별 집계 + 공공데이터(날씨, 신대방역 승하차 인원, 공휴일) + 블로그 체험단 광고·리뷰 조회수 기록
- **규모:** 730일(2024-07-01 ~ 2026-06-30) × 25개 변수
- **문제 유형:** 예측(회귀) + 군집

> 주점 한 곳의 2년치 일매출을 요일·공휴일·영업 흐름·날씨·유동인구·광고 변수로 예측하고 그날의 주문 구성으로 영업일 유형을 나눴다.
> 매출 계산식에 들어가거나 장사가 끝나야 알 수 있는 POS 변수는 **예측(묶음 A)에서 빼고 군집(묶음 B)에만 썼다.**
> 회귀 모델 11종을 기본·튜닝 버전으로 나눠(총 22개) 기준선 3개와 비교한 결과 최종 모델(Ridge)의 테스트 MAE는 269,120원으로 전체 평균 기준선보다 17.3% 낮았다.
> 하지만 **요일별 중앙값 기준선과의 차이는 1.9%였고 통계적으로 유의하지 않았다**(윌콕슨 검정 p = 0.18). 일매출은 요일로 대부분 설명된다는 뜻이다.
> 그래서 매일 모델을 돌리는 예측 대신 요일별 매출 수준과 K-Means로 나눈 5개 영업일 유형을 합쳐 **요일 기반 운영 캘린더**를 최종 산출물로 만들었다.

## 핵심 결과

| 항목 | 내용 |
|---|---|
| 최종 모델 | Base Ridge — `log(매출액) ~ 요일 + 공휴일여부 + 공휴일전날여부 + 연휴여부 + dow_ma4 + lag1_매출 + lag7_매출 + 연속영업일수 + lag1_리뷰조회수 + 광고_실시여부 + 광고_경과일수` (영업일 690일, 시계열 5겹 교차검증으로 선정) |
| 예측 성능 | 테스트 MAE = 269,120원, RMSE = 411,020원, R²(로그) = 0.144 &nbsp;/&nbsp; CV MAE = 308,706원, 과적합 Gap 3.37% |
| 요일 기준선 대비 | MAE 5,326원(1.9%) 낮지만 유의하지 않음(p = 0.18). 오차 감소분의 약 91%는 요일만으로 얻을 수 있는 몫 |
| 매출 요인 (SHAP) | 요일이 기여도의 약 55%. 화요일 대비 토 +0.48 > 일 +0.38 > 금 +0.32 (로그 척도). 공휴일 +0.31 |
| 확인되지 않은 요인 | 기온·강수·기상특보·유동인구는 무관. 리뷰 조회수 효과는 대부분 개업 초기 효과였고 광고의 순수 효과는 확인되지 않음 |
| 영업일 유형 (K-Means) | k = 5, 영수증 3건 이상인 610일. 대량 주문형 · 술자리 중심형 · 원웨이브 러시형 · 식사 중심형 · 라이트 방문형 (실루엣 0.22, ARI 0.83~0.94) |
| 최종 산출물 | 요일·공휴일별 매출 중앙값, 손님이 매우 적은 날의 비율, 유형 출현 비율을 묶은 운영 캘린더 |
| 이번에 연습한 기법 | 데이터 누수를 막는 변수 역할 분리, 시계열 분할과 `TimeSeriesSplit`, 기준선 비교와 윌콕슨 검정, 하이퍼파라미터 튜닝, 과적합 진단, SHAP 해석, K-Means와 군집 안정성(ARI) 점검, 카이제곱 검정과 홀름 보정 |

## 회고

- **새로 익힌 기법:** 시계열 데이터를 시간 순서대로 나누고 `TimeSeriesSplit`으로 교차검증하는 방법, 모델을 **단순 기준선과 짝지어 비교하고 검정하는 방법**(윌콕슨 부호순위 검정), SHAP으로 선형 모델의 변수 기여도와 요일별 예측을 분해하는 방법, 그리고 군집 결과를 시드·부분표본 재군집(ARI)으로 점검하는 방법이다.
- **막혔던 지점과 해결 방법:**
  - ① POS 변수 중에는 매출 계산식에 직접 들어가거나 장사가 끝나야 확정되는 값이 많아 그대로 넣으면 답을 미리 보는 셈이었다 → **계산식 포함 여부와 예측 시점에 알 수 있는지**를 기준으로 변수 역할을 나눠 예측에는 빼고 영업일 유형을 나누는 군집에만 썼다.
  - ② 전날 리뷰 조회수가 매출과 관련 있어 보였지만 조회수가 0인 날이 광고 시작 전인 개업 초기에 몰려 있었다 → 학습 구간을 광고 시작 이후로 한정해 다시 학습했더니 기여도가 약 5분의 1로 줄었다(6위 → 13위). 리뷰 효과처럼 보였던 것은 대부분 **개업 초기의 낮은 매출**이었다.
  - ③ 최종 모델을 고르고 다음 날 매출을 예측하는 파이프라인까지 만들었지만 요일별 중앙값 기준선과 비교하니 차이가 유의하지 않았다 → 미리 정해 둔 판단 기준에 따라 결론을 바꾸고 예측 파이프라인 대신 **요일 기반 운영 캘린더**로 방향을 틀었다.
  - ④ 처음에는 영업일 유형이 결국 '손님이 많이 온 날'을 다시 나누는 데 그쳤다 → 영수증 수와 거의 무관한 `팀당_주문수량`(ρ = 0.036)으로 입력을 바꾸고 영수증 2건 이하인 날을 빼자, 유형이 **주문 내용과 시간대**로 나뉘었다.
- **다음 데이터셋에서 보완할 점:** 변수를 고를 때 테스트 구간까지 포함한 전체 데이터를 썼고 원래 금액 기준으로 하나씩 검정해 요일 효과에 가려진 변수를 놓쳤을 수 있다. 다음에는 **학습 구간만으로, 모델과 같은 로그 척도에서, 요일을 함께 고려해** 변수를 고르고 싶다. 광고 효과처럼 다른 요인과 섞인 효과는 광고를 켜고 끄는 기간을 번갈아 두는 식으로 처음부터 비교할 수 있게 설계해야 한다.
