## 📝 INTRODUCTION

UX 심리학을 공부하며 고객의 행동을 관찰하고, 그 행동이 나타나는 이유를 파악하는 데 관심을 갖게 되었습니다. 이후 데이터 분석을 배우면서 이러한 관심을 실제 데이터로 확인하는 과정에 흥미를 느꼈습니다.

저는 데이터를 분석하는 데서 그치지 않고, 결과를 바탕으로 문제의 원인을 찾고 실제로 적용할 수 있는 해결 방안까지 고민합니다. 수치가 의미하는 바를 해석하는 것뿐 아니라, 그 결과가 의사결정에 어떻게 활용될 수 있는지도 함께 살펴봅니다.

주점 매출 분석 프로젝트에서는 여러 예측 모델의 성능을 비교하고, 예측 결과를 실제 매장 운영에 활용할 수 있는지 검토했습니다. 선택한 모델의 예측 오차는 요일 평균보다 4.1% 작았지만, 두 방식의 오차 차이를 일매출 기준으로 환산하면 약 5,600원이었습니다. 이 정도 차이로 식자재 준비량을 별도로 조정할 필요성은 크지 않다고 판단해 요일 평균을 최종 기준으로 채택했습니다. 이후 요일 평균을 바탕으로 운영 캘린더를 제작해 매장 운영에 참고할 수 있도록 정리했습니다.

식료품 마트 CRM 프로젝트에서는 전체 구매액이 늘어나는 가운데 구매가 꾸준히 줄어든 370가구를 찾아, 원인 가설을 세우고 비슷한 가구끼리 짝지어 비교했습니다. 과거 캠페인 효과는 매칭과 이중차분으로 추정했고, 이를 바탕으로 CRM 접촉 대상과 순서, 무작위 실험 설계까지 제안했습니다. 분석 전 가설과 검증 기준을 세우고, 예상과 다른 결과가 나오면 기존 가설에 얽매이지 않고 다른 가능성을 검토합니다.

### PROJECT 01. 소규모 주점의 일매출 예측과 영업일 유형화

**머신러닝 · 회귀 분석 · 군집 분석 | 3인 팀 프로젝트**

**역할** 분석 설계 공동 기획, POS 원천 데이터 집계·전처리·모델링 코드 작성 주도. 프로젝트 종료 후 데이터 집계 오류를 고쳐 다시 분석하고, 최종 운영 캘린더를 단독으로 도출

#### 프로젝트 배경

일매출이 날에 따라 최대 6배까지 차이 나는 매장에서, 발주·재료 손질·인력 배치를 미리 정할 때 참고할 매출 기준이 없었습니다.

#### 분석 과정

일매출 예측에 적합한 모델을 찾기 위해 회귀 모델 13종을 롤링 평가 방식으로 비교했습니다. 각 모델의 예측 오차를 확인하고, 요일 평균을 기준으로 한 단순 예측과도 비교했습니다. 매출을 방문 팀 수와 객단가로 나누고, POS와 외부 데이터를 결합한 일별 분석 테이블을 만들어 매출 변동과 관련된 요인을 살펴봤습니다. 모델링에서 제외한 변수까지 활용해 영업일을 5개 유형으로 군집화하고, 각 유형을 미리 알아볼 수 있는 조건도 탐색했습니다.

#### 주요 결과

선택한 모델의 예측 오차는 요일 평균보다 4.1% 작았습니다. 하지만 두 방식의 오차 차이를 일매출 기준으로 환산하면 약 5,600원이었습니다. 모델의 예측 성능은 더 좋았지만, 이 정도 차이로 식자재 준비량을 별도로 조정할 필요성은 크지 않다고 판단했습니다. 이에 요일 평균을 최종 기준으로 채택했습니다.

#### 실무 적용

채택한 요일 평균에 매출 유형별 출현 빈도와 사전 조건을 더해 매장 운영 캘린더를 제안했습니다. 복잡한 예측 모델의 결과보다 매장에서 쉽게 참고하고 활용할 수 있는 기준을 제시하는 데 초점을 맞췄습니다.

이 프로젝트를 통해 예측 성능이 높은 모델을 선택하는 것만큼이나, 그 결과가 실제 현장에서 어떤 의미를 갖는지 판단하는 과정도 중요하다는 점을 배웠습니다. 분석 결과를 실무에 연결하려면 수치의 차이뿐 아니라 현장에서 활용할 수 있는 수준의 차이인지도 살펴봐야 했습니다.

### PROJECT 02. 식료품 마트 이탈 방지 CRM 타기팅 분석

**추세 검정 · 최근접 매칭 · 이중차분 | 1인 프로젝트**

#### 프로젝트 배경

식료품 마트 2,500가구의 102주 구매 기록을 보면 전체 구매액은 5.5% 늘었지만, 그 안에서 구매가 꾸준히 줄어드는 가구가 있었습니다. 평균 성장에 가려진 고객 감소를 분석 과제로 삼았습니다.

#### 분석 과정

84주 구매 기록에 Mann-Kendall 추세 검정을 적용해 구매가 지속적으로 감소한 370가구(전체의 15.4%)를 찾았습니다. 이들의 구매액은 1년 사이 61.2% 줄었습니다.

원인은 장보기 자체가 줄었는지, 다른 곳으로 구매처를 옮겼는지 등으로 가설을 나눠 살폈습니다. 감소 전 구매액과 방문 수가 비슷한 가구를 짝지어 비교한 결과, 단골 품목을 끊은 비율이 18.0%로 방문 감소만으로 예상되는 4.2%보다 높았습니다. 일부 구매처 이동 가능성을 보여 주는 결과이지만, 다른 구매처 기록이 없어 단정할 수는 없습니다.

과거 캠페인 21개는 캠페인을 받기 전 구매 수준과 추세가 비슷한 미수신 가구와 최근접 매칭한 뒤 이중차분으로 효과를 추정했습니다. 데이터에 정의된 캠페인 유형 중 B형은 캠페인 종료 후 4주당 구매액 효과가 +4.5~6.4%로 추정됐지만, 구매 규모에 따라 효과의 방향이 달라 모든 가구에 같은 캠페인을 적용하기는 어렵다고 판단했습니다.

#### 결과

감소 양상에 따라 서서히 줄어든 274가구, 한 번에 줄어든 67가구, 방문을 끊은 29가구로 나누고, 끊긴 단골 품목과 되찾을 몫을 바탕으로 CRM 접촉 대상과 순서, 쿠폰을 포함한 안내 방안을 제안했습니다. 효과를 검증할 수 있도록 무개입 비교군을 둔 12주 무작위 실험과 최소 검출 효과까지 설계했습니다. 실제 캠페인 집행과 성과 검증은 하지 않았습니다.

### PROJECT 03. 투두메이트 사용자 이탈 원인과 미충족 니즈 분석

**UX 리서치 · 심층 인터뷰 · 사용자 행동 분석 | 4인 팀 프로젝트**

**역할** 리서치 분석 설계 전반 담당, 인터뷰 질문지 공동 제작, 심층 인터뷰와 결과 분석, 발표 참여

#### 프로젝트 배경

신규 설치자의 1일차 이탈률이 27.6%에 달하고, 기존 이용자도 기능 업데이트에 대한 불만을 꾸준히 드러내는 상황이었습니다. 이탈 원인과 지속 이용자의 미충족 니즈를 파악해 서비스 개선 방향을 마련하고자 했습니다.

#### 분석 과정

서비스의 기능 확장이 기존 이용자의 사용 목적과 맞지 않을 가능성에 주목했습니다. 이탈 이용자 3명과 지속 이용자 4명을 심층 인터뷰해 이용 행태, 기능 인식, 다른 앱을 함께 쓰는 이유를 비교했습니다.

#### 결과

초기 가설과 달리 두 그룹이 원하는 기능의 차이는 작았고, 생활 습관과 할 일 관리 성향에서 차이가 보였습니다. 이를 바탕으로 성향별 기능 적합성을 검토해 맞춤형 대시보드, 캘린더·시간대별 일정 관리, 알림 기능 개선안을 제안했습니다.

### 그 밖의 프로젝트

- **Olist 고객 재구매 패턴 분석 (3인)** · RFM 분석으로 고객 약 97%가 한 번만 구매한 것을 확인하고 주문금액·지역·상품 카테고리별 구매 특성을 비교했습니다. 주문 데이터만으로는 재구매가 낮은 원인을 특정하기 어렵다고 보고, 고객 불만과 구매 경험에 대한 추가 분석이 필요하다고 정리했습니다.
- **캐치테이블 예약·웨이팅 UX 개선 (4인)** · 예약·웨이팅 과정의 사용자 여정과 감정 흐름을 분석하고 UX 심리 법칙을 적용해 사용 경험을 평가했습니다. 예약 완료 전 단계의 부정적 경험을 개선 대상으로 정하고 정보 제공 방식과 인터페이스 개선안을 제안했습니다.
