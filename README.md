**01. 소규모 주점의 일매출 예측과 영업일 유형화** (3인)
실제 운영 중인 주점에서 하루 매출이 최대 6배까지 달라지는 문제를 다뤘다. 회귀 모델 13종을 롤링 평가한 결과, 선택한 모델의 오차는 요일 평균보다 4.1% 작았다. 다만 하루 차이는 약 5,600원으로 운영 준비량을 바꿀 정도가 아니라고 판단해, 요일 평균을 준비 기준으로 삼고 매출 유형별 출현 빈도를 담은 운영 캘린더를 만들었다.

**02. 식료품 마트 이탈 방지 CRM 타기팅 분석** (1인)
2,500가구의 102주 구매 기록에서 84주 동안 구매가 꾸준히 줄어든 370가구(15.4%)를 찾았다. 이들의 구매액은 감소 전 전체 구매액의 22.1%였다. 가설 10개를 검증해 장보기의 일부를 다른 곳으로 옮겼을 가능성을 확인했다. 과거 캠페인 21개는 캠페인 전 구매 흐름이 비슷한 가구끼리 비교해 반응 차이를 분석했다. CRM 시나리오와 실험 설계는 진행 중이다.

**공통 분석 모듈 `helpers`** — 품질 점검(`my_qtcheck`) · 시각화(`my_plot`) · 통계 검정(`my_stats`) · 전처리(`my_prep`) · 선형회귀(`my_ols`) · 로지스틱 회귀(`my_logit`) · 시계열(`my_ts`) · 머신러닝(`my_ml`) · 군집(`my_cluster`) · 모델 진단(`my_diag`)
