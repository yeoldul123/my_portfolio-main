### 1) 소규모 주점의 일매출 예측과 영업일 유형화 (3인)

`Python` · `선형회귀` · `K-Means` · `SHAP`

- **역할:** 분석 설계 공동 기획, POS 원천 데이터 집계·전처리·모델링 코드 작성 주도. 프로젝트 종료 후 데이터 집계 오류 수정 및 재분석, 최종 운영 캘린더 단독 도출.
- **문제 정의:** 상·하위 10% 날의 하루 매출이 6배 가까이 차이 나는 매장에서 발주·재료 손질·인력 배치를 사전에 결정할 매출 참고 기준 부족.
- **원인 탐색:** 매출을 방문 팀 수와 객단가로 분해하고, POS·외부 데이터를 결합한 일별 분석 테이블 구축. EDA와 통계분석으로 매출 변동 관련 요인 탐색.
- **분석 및 대안 검토:** 예측 모델 13종의 성능을 비교하고, 모델링에서 제외한 변수까지 활용해 영업일을 5개 유형으로 군집화하여 사전 식별 조건 탐색.
- **결과: 선정한 선형회귀의 오차(MAE)가 438일 롤링 평가에서 요일 평균보다 4.1% 작았지만(모델 선정에 쓴 기간 포함), 하루 약 5,600원 차이에 그쳐 단순한 요일 평균을 운영 기준으로 채택. 요일 기준 매출·준비 범위·유형 출현 빈도를 담은 매장 운영 캘린더 제안.**

### 2) 식료품 마트 이탈 방지 CRM 타기팅 분석 (1인)

`Python` · `로직트리` · `Mann-Kendall 추세 검정` · `최근접 매칭` · `이중차분(DID)`

- **문제 정의:** 식료품 마트 2,500가구의 102주 구매 기록 중 분석 대상 2,405가구의 84주 구매 추세를 검정해, 꾸준히 구매를 줄인 370가구(15.4%)를 식별. 전체 구매액은 5.5% 늘었지만 이들은 1년간 61.2% 줄어, 평균 성장에 가려진 고객 감소를 분석 과제로 설정.
- **원인 탐색:** '장보기 자체의 감소'와 '다른 매장으로의 이동' 등으로 가설을 나누고, 감소 전 구매가 비슷한 가구와 짝지어 비교. 끊긴 단골 품목에 쓰던 구매액 비중(중앙값)이 방문 감소만으로 예상되는 4.2%보다 높은 18.1%로 나타나, 장보기 일부를 다른 매장으로 옮겼을 가능성 제시(타 매장 기록 없어 가설을 통한 추정).
- **분석 및 대안 검토:** 옮겨 간 구매를 되찾을 수단을 찾기 위해, 과거 쿠폰 캠페인 21개의 효과를 받기 전 구매 흐름이 비슷한 미수신 가구와 짝지어 비교. 같은 쿠폰 묶음을 보낸 B형은 종료 후에도 구매액이 4.5~6.4% 높게 유지됐으나, 원래 적게·중간쯤 사던 가구에서만 늘어 일괄 적용은 어려움.
- **결과: 감소 양상에 따라 서서히(274)·한 번에(67)·방문 중단(29가구)으로 나누고, 끊긴 단골 품목과 그 품목의 과거 구매액을 기준으로 연락 대상·순서와 쿠폰을 담은 안내 방안 제안. 효과는 과거 기록만으로 단정할 수 없어, 비교군을 둔 12주 무작위 실험과 최소 검출 효과까지 설계(실제 집행·성과 검증은 미수행).**

### 3) 투두메이트 사용자 이탈 원인 및 미충족 니즈 분석 (학부 팀 프로젝트, 4인)

- **결과: 사용자별 할 일 관리 성향과 기존 기능의 인지도 차이를 고려해 맞춤형 대시보드, 캘린더·시간대별 일정 관리, 알림 기능 개선안 제안.**

## 🧩 REUSABLE ANALYSIS MODULES

프로젝트마다 반복해서 사용하는 분석 기능을 모듈로 정리했습니다. 데이터 품질 점검부터 전처리, 통계 검정, 시각화, 모델링까지 필요한 기능을 재사용할 수 있도록 구성했습니다. 모듈 코드는 이 저장소에 포함하지 않았습니다.

| 모듈 | 주요 기능 |
|---|---|
| `my_qtcheck` | 데이터 품질 점검 |
| `my_plot` | 데이터 시각화 |
| `my_stats` | 통계 검정 |
| `my_prep` | 데이터 전처리 |
| `my_ols` | 선형회귀 분석 |
| `my_logit` | 로지스틱 회귀 분석 |
| `my_ts` | 시계열 분석 |
| `my_ml` | 머신러닝 |
| `my_cluster` | 군집 분석 |
| `my_diag` | 모델 진단 |

아이티윌 이광호 강사님의 [`hossam`](https://py.hossam.kr) 라이브러리를 바탕으로 구성했습니다.
